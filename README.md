## 🚀 Getting Started

Want to check it out locally? Here's how I run it:

### Quick Preview
Just open `index.html` in your browser - no server needed for basic viewing.

### With a Local Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```

Using Node.js:
```bash
npx http-server -p 8000
```

Then visit `http://localhost:8000`

## 📝 For Fellow Developers

If you're looking to use this as a template for your own portfolio:

### Personalize It
- Update the hero section with your info
- Replace the projects with your own work
- Change the color scheme in the CSS variables
- Update the contact form endpoint (I use Formspree)
- Add your social links and contact info

### Customize Colors
In the inline styles, look for the CSS custom properties:
```css
:root {
  --color-emerald: #10b981;  /* Change this to your brand color */
}
```

### Add Your Projects
In `index.html`, find the projects section and swap out my examples with yours.
